# hxwl-12 心理咨询个案台账

个案 · 风险会谈 · 联系尝试 · 安全计划 —— 服务于会谈间隙快速接续危机跟进。

## 技术栈

React + Vite + TypeScript + CSS，数据仅保存在本机浏览器（localStorage），无后端。

## 本地运行

```bash
npm install
npm run dev          # 开发，端口 5112
npm run typecheck    # 类型检查
npm run build        # 生产构建
npm run test:domain  # 判断层业务规则验证（零额外依赖，esbuild 转译后运行）
```

## 台账工作流（与需求对应）

1. **高风险会谈留痕**：录入高风险会谈时强制填写
   紧急联系人、下次跟进时刻、一次联系尝试的结果；缺项无法保存。
2. **联系失败保留并顺延**：每次拨打/短信/紧急联系人尝试都按时间留存在会谈卡片内；
   失败时必须把"下次跟进时刻"向后顺延（判断层拒绝把时间提前）。
   到期未接通自动标红为"已逾期"，页面每 30 秒刷新该状态。
3. **接通才算完成**：任一次尝试标记"已接通"后危机跟进完成，之后不能再补记尝试。
4. **不能悄悄结案**：结案是显式按钮，闸门检查——高风险跟进全部接通、
   连续两次低风险 + 督导确认降级、有会谈记录、填写结案理由，缺一不可。
5. **降级双低 + 督导**：最近一次高风险会谈之后必须连续两次低风险
   （中间再出高风险则计数清零），且无未完成的危机跟进，督导确认后
   **生成新风险版本，旧版本只追加不改写**，可在"风险版本记录"中审计。
6. **安全计划版本化**：每次保存生成新版本（需来访者确认同意），历史版本可展开查看。
7. **草稿按个案隔离**：会谈/安全计划草稿以 `个案ID + 表单` 分键存入 localStorage，
   切换个案装载的是该个案自己的草稿，不串台；保存成功或"清空草稿"后清除。

## 代码分层（资料 / 判断 / 本地保存 / 页面 分开）

| 目录 | 职责 |
| --- | --- |
| `src/data/` | **资料层**：`types.ts` 领域类型、`seed.ts` 示例台账（时间相对当前时刻生成）、`project.ts` 页面元信息 |
| `src/domain/` | **判断层**：纯函数，无 DOM/React/存储依赖。`followup.ts`（跟进状态/顺延）、`risk.ts`（风险状态/两低计数/降级条件）、`safety.ts`（安全计划校验/结案闸门）、`commands.ts`（所有台账变更命令，统一 `Result` 返回） |
| `src/storage/` | **本地保存层**：`ledgerStore.ts` 台账读写/损坏提示/导出/恢复示例，`draftStore.ts` 按个案分键的草稿存取 |
| `src/state/` | 胶水：`useLedger`（命令→状态→落盘→错误提示）、`useCaseDraft`（个案草稿隔离） |
| `src/ui/` | **页面层**：指标栏、个案列表、会谈录入、时间线/尝试补记、降级面板、安全计划、结案面板 |

业务规则全部集中在判断层，可脱离浏览器验证：`test/domain.test.ts` 覆盖
高风险必填、失败顺延/逾期/接通终态、两低+督导降级（含中间高风险重置）、
版本保留、结案闸门、结案后锁定等 6 组规则。
