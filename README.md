# hxwl-12 心理咨询个案记录

危机跟进台账：个案、风险会谈、联系尝试与安全计划串联入账。

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5112

## 分层结构

- `src/data/` 资料：领域模型（`types.ts`）与示例台账（`seed.ts`）
- `src/domain/` 判断：纯函数业务规则（`ledger.ts`），不碰 DOM 与存储
- `src/storage/` 本地保存：localStorage 读写（`localStore.ts`），数据损坏时回落到种子
- `src/ui/` 页面：React 组件，`App.tsx` 负责组装

## 台账规则

- **高风险会谈必填**：紧急联系人、下次跟进时刻、至少一次联系结果，否则无法入账
- **联系失败**：每次尝试保留在台账中，下次跟进时刻自动顺延 24 小时，跟进保持开放
- **不能悄悄结案**：存在未接通的高风险跟进时，结案被拦截并列出原因
- **风险降级**：需连续两次低风险会谈且无待接通跟进，由督导确认后生成新评估版本，旧版本保留可查
- **安全计划版本化**：每次修订生成新版本，历史版本可展开查看
- **草稿隔离**：会谈草稿按个案分别保存（localStorage），切换个案不串台
